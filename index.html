QUESTION 1 (4 POINTS)CONCEPT COMPARISONS
A. Multiprogramming vs. Multitasking (Time-Sharing) (2 Points):
Give two fundamental differences between multiprogramming and multitasking.
Difference 1: Objective. Multiprogramming maximizes CPU utilization by keeping multiple jobs in memory; Multitasking minimizes response time so interactive users can interact with programs concurrently.
Difference 2: Switching Trigger. Multiprogramming switches only when the active job waits for I/O; Multitasking switches frequently via a hardware timer interrupt even if the process is computing.
B. Shared Memory vs. Message Passing (IPC Models) (2 Points):
Give two fundamental differences between Shared Memory and Message Passing.
Difference 1: Kernel Involvement. Shared memory requires kernel involvement only once to establish the mapping, then transfers occur at memory bus speed; Message passing requires kernel system calls for every message exchange.
Difference 2: Network Applicability. Message passing works naturally across distributed network nodes; Shared memory is difficult to implement across different machines without distributed hardware.
QUESTION 2 (5 POINTS)DUAL-MODE & PARALLELISM
A. Mode Transition Trace (3 Points): During a system call, what are the 6 steps and mode bit values?
1. User process executing in User Mode (Mode bit = 1).
2. Executes system call trap instruction.
3. Hardware flips Mode bit to 0 (Kernel Mode).
4. CPU indexes into Interrupt Vector Table (IVT) to locate system call handler.
5. Kernel executes privileged service routine in Ring 0.
6. Return-from-trap instruction restores Mode bit to 1 and resumes user program.
B & C. Parallelism in Array Addition (2 Points):
A program adds 5 to every element of an array of 1,000 numbers by splitting it into 4 parts of 250 across 4 cores. Which type of parallelism is this? Justify.
Answer: Data Parallelism.
Justification: The identical arithmetic operation (+5) is applied concurrently across multiple sub-partitions of the same dataset. (Task parallelism would involve executing different functions on each core).
QUESTION 3 (5 POINTS)BOUNDED BUFFER TRACE
Explain the exact purpose of:
1. while (in == out); in the consumer process.
2. % BUFFER_SIZE in out = (out + 1) % BUFFER_SIZE;
1. while (in == out); blocks (busy-waits) the consumer when the buffer is completely empty, preventing it from consuming uninitialized or already-consumed memory.
2. % BUFFER_SIZE implements a circular ring buffer, wrapping the index back to 0 when it exceeds array boundaries and reusing empty slots.
QUESTION 4 (5 POINTS)CRITICAL SECTION & PETERSON
A. Software Attempt 1 (turn variable): Is Mutual Exclusion, Progress, and Bounded Waiting satisfied under sequential processing?
• Mutual Exclusion: Satisfied. Only one process can match turn at a time.
• Progress: NOT SATISFIED! Enforces strict alternation. If P1 is in remainder section, P0 cannot enter twice.
• Bounded Waiting: NOT SATISFIED! P0 waits indefinitely for P1.
QUESTION 5 (3 POINTS)SEMAPHORE DEADLOCK
Threads T1 and T2 share semaphores S=1 and Q=1. T1 executes wait(S); wait(Q); while T2 executes wait(Q); wait(S);.
Why is output "Nothing is printed" possible? What is this problem called?
Problem: Deadlock (Circular Wait).
T1 executes wait(S) (S=0). Context switch occurs. T2 executes wait(Q) (Q=0). Now T1 blocks waiting for Q, and T2 blocks waiting for S. Neither can proceed.
Fix: Enforce strict resource acquisition ordering: both threads must call wait(S) before wait(Q).

Find Completion Time, TAT, WT, and Average Waiting Time.
